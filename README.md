### 02 / 项目经历 · Project Experience

#### 工作项目 / Professional Projects

**Lux3D 大模型分布式推理基础设施**  
*架构设计与核心开发*

负责两套分布式推理服务的整体架构、核心开发与交付，支撑 AI PBR、GaussMesh 及 Lux3D 多版本模型应用。建设任务并行、分阶段流水线、编译产物与上下文复用、分级调度和弹性扩缩容，完善标准推理接口、版本治理、全链路监控与异常定位。

[访问 Lux3D / Live Website ↗](https://lux3d.aholo3d.cn/lux3d/home) · [Lux3D Skill ↗](https://labs.aholo3d.cn/api-docs/skills/lux3d)

**材质翻译模型训练与业务落地**  
*训练优化与效果对齐*

围绕 OC、C4D、KeyShot 等渲染器材质到 PBR 表达的转换，负责数据定义、自动化数据生产与训练优化。定位色差、贴图、节点参数及 UV 等失败案例，开展 SFT、多模态数据组合实验与基于渲染反馈的 RL 后训练，建设固定测试集、自动评测和可视化报告，并完成模型部署与业务接入。

**AI 素材标签体系与规模化语义打标**  
*架构设计与工程落地*

设计质量闸门、事实标签、语义感知和下游应用的分层架构，负责标签、素材及打标事实的数据模型与语义感知流程落地。打通素材筛选、渲染、分类打标、存储索引、训练导出与向量检索，记录模型、提示词和任务版本，支撑三维素材搜索、运营与模型训练。

**AI PBR 数据治理与 GaussMesh 数据工程**  
*数据供给与训练实验*

负责存量三维数据分类打标、质量清洗、去重、类别均衡和精选训练集交付。建设 GaussMesh 数据生产、格式转换、多视角渲染、版本管理与训练数据交付链路，参与 GS2Shape DiT、GS2Shape & PBR DiT 训练实验，并开展 VLM 打标能力评测及调用成本分析。

**Lux3D 产品化与模型评测工具**  
*全栈开发与平台能力建设*

完成 Lux3D 网站前后端初期建设、OpenAPI、模型能力原型及基础功能管线，提供模型试用、效果展示与应用验证入口。建设第一版 Qunhe 3D Arena，以及评测、调试、可视化和自动化测试工具，通过自动评测与主观盲评支撑模型对比、版本选择和效果迭代。
